Conserver votre budget

Votre budget est enregistré sur votre appareil. Dans Éparilo, ouvrez Menu → Réglages → Sauvegardes et données → Enregistrer une sauvegarde JSON, puis conservez ce fichier dans le dossier de votre choix.

Restaurer une sauvegarde JSON permet de retrouver ses données. L’assistance ne dispose pas d’une copie de votre budget et ne peut pas le récupérer à distance.
